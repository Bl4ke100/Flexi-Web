# FLEXI RENTAL Sri Lanka

A modern, high-craft car rental website for **Flexi Rental**, an everyday car rental service based in Sri Lanka.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) 14 (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations & Micro-interactions**: [Framer Motion](https://www.framer.com/motion/)
- **3D Graphics**: [Three.js](https://threejs.org/) & [@react-three/fiber](https://r3f.docs.pmnd.rs/)
- **Icons**: [Lucide React](https://lucide.dev/)

## Features

- **LFG-Style Editorial Design**: Strictly shades of Orange (`#FF5500`), Black (`#050505`), and White (`#FFFFFF`).
- **Precision Fluid Cursor**: Full-viewport Canvas 2D fluid smoke trail with 1:1 pixel-aligned cursor ring.
- **Preloader Curtain Reveal**: 3-digit slot-reel preloader with 24-stripe curtain reveal.
- **Sudden Horizontal Scroll Reel**: Pinned route reel featuring Sri Lankan scenic routes (Katunayake BIA, Colombo, Kandy/Ella, Galle Coast, etc.).
- **Scrollytelling Sections**: Interactive service showcase, 30-tick radial gauge process, and 3D tilt collage grid.
- **3D Helical Film Tape Gallery**: True 3D bending helical film tape in Three.js where photos curve around the text and glide smoothly.
- **Fleet Showroom & Comparison**: Detailed specs for Sri Lankan everyday vehicles (hybrid hatchbacks, sedans, SUVs, and KDH high-roof vans) in LKR rates.
- **Interactive Trip Pricing Calculator**: Live rate estimator with mileage options, multi-day discounts, and airport/driver add-ons.
- **Island-Wide Hubs & Booking**: Pickup coverage across Colombo, Katunayake Airport, Kandy, Galle, Negombo, and Ella.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
